• To get an accessible PDF, make sure everything is completely up to date, and as the very first lines in your TeX file: 
    \DocumentMetadata{tagging=on,lang=en-US,pdfstandard=ua-2,
 % check-tagging-status, % uncomment to log status of packages
 tagging-setup={
  % math/alt/use, % uncomment for Ally
  math/setup=mathml-SE
 }
}
